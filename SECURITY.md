# Security Policy

## Supported version

The currently supported release is **v0.1.4**.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting / Security Advisories when available. If private reporting is unavailable, contact the maintainer through the GitHub profile before disclosing technical details publicly.

Include the affected version, impacted component, reproduction steps, expected versus observed behavior, and security impact when possible. Do not include credentials, private tokens, personal data, or unrelated sensitive information.

## Scope

Reports about EU Tender Scout itself are in scope. Issues in third-party services or upstream data sources should normally be reported upstream unless the vulnerability is caused by EU Tender Scout's integration behavior.
